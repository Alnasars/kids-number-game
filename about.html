123 Number Fun Game: a free math game for young children

123 Number Fun Game is a free online math game for children aged 2 to 8. It helps young children learn to count, read numbers, add, take away and find missing numbers. The game speaks each question aloud, so children can learn by listening as well as by seeing.

What children learn

  • Counting and reading numbers: Toddler Mode lets a child tap a number and hear it, or see a number and tap the matching button. Levels cover 1 to 10 and 11 to 20.
  • Addition and subtraction: The main game starts with small sums and gets harder as the child keeps answering correctly.
  • Missing numbers: Children find the missing part of an addition or subtraction.
  • Multiplication tables: Parents can choose tables from 1 to 3 up to 1 to 25.

How it works

Open the game in any web browser on a phone, tablet or computer. There is no download and no signup. Children earn a star sticker for every five correct answers and can fill a sticker album. After five correct answers, a parent can create a printable or shareable certificate with the child's name.

Privacy

The game does not ask for emails or accounts. A child's name, stickers and progress are saved only on the device the game is played on, so the game can say welcome back. This information is never sent to our servers. The game uses Google Analytics and Vercel Analytics to see which parts of the game are used, as explained in our Privacy Policy.
